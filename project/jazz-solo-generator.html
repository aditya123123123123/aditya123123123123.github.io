CASE STUDY / 01

JazzML / Jazz Solo Generator

ONGOING ML/MUSIC RESEARCH — EVALUATION FIRST
RoleResearch, implementation, evaluation
StackPyTorch · MIDI · Music21
DataWeimar Jazz Database
StatusActive research — no promoted model

The problem

I wanted a research workflow that could test jazz rhythm and melody ideas against the same data and listening standards. The project uses the Weimar Jazz Database and treats a runnable baseline, controlled comparisons, and careful records as more useful than a single impressive clip.

What I built

I direct AI-agent-assisted experiments on jazz rhythm and melody using the Weimar Jazz Database. The workflow includes PyTorch models, train-only data handling, multi-seed metrics, protected evaluation panels, provenance checks, and a deterministic melodic carrier for a limited retrieval/template baseline.

  • Multi-seed comparisons and protected evaluation panels to reduce accidental promotion of a lucky run
  • Train-only retrieval/template experiments with a deterministic melodic carrier for a runnable baseline
  • Provenance and reproducibility checks that keep data, code, and evaluation context attached to each run
  • Listening gates alongside structured metrics before a model or version is described as better

The part most people skip: evaluation

I use structured metrics and listening gates together. Runs that failed the predeclared density or rhythm-distribution criteria stayed rejected; a lower loss or a code change is not enough to call a model better.

Research boundaries

  • The current baseline is limited and remains unpromoted until its declared rhythm and density criteria are met
  • Model comparisons stay tied to a provenance record, reproducibility checks, and a protected evaluation panel
  • Listening remains part of the gate; metrics alone do not establish that a musical result is better

Current state

The current public-facing baseline is a limited train-only retrieval/template rhythm system with a deterministic melodic carrier. It is a runnable research baseline, not a promoted generative model.
